# Chrome Web Store listing images

These are the images uploaded to the JiitSphere Connect listing in the Chrome
Web Store developer console. They are not part of the extension package.

Screenshots and promo tiles must not have an alpha channel, so each is a 24-bit
PNG. The 128 x 128 icons keep their transparent padding, which the store asks for.

| File | Size | Used for |
|---|---|---|
| `icon-128.png` | 128 x 128 | Store icon. The logo is 96 x 96 with 16 px of transparent padding, as the store asks. |
| `icon-128-solid-rgb.png` | 128 x 128 | Alternative store icon on a solid dark background. |
| `icon-128-rounded.png` | 128 x 128 | Rounded variant of the icon. |
| `screenshot-1-dashboard.png` | 1280 x 800 | Screenshot 1: the attendance overview. |
| `screenshot-2-materials.png` | 1280 x 800 | Screenshot 2: study material search. |
| `screenshot-3-attendance.png` | 1280 x 800 | Screenshot 3: the attendance calculator. |
| `screenshot-4-grades.png` | 1280 x 800 | Screenshot 4: grades and CGPA. |
| `screenshot-5-exams.png` | 1280 x 800 | Screenshot 5: the exam schedule. |
| `screenshot-login-google.png` | 1280 x 800 | Spare screenshot of the Google sign-in. |
| `promo-small-440x280.png` | 440 x 280 | Small promo tile. |
| `promo-marquee-1400x560.png` | 1400 x 560 | Marquee promo tile. |

The store takes at most five screenshots. The image rules are at
https://developer.chrome.com/docs/webstore/images.
